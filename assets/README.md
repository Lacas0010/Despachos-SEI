# Ícones do Gerador SEI

Esta pasta contém os ícones utilizados pela aplicação. Os ícones foram criados automaticamente usando PIL/Pillow.

## Ícones Criados:

- `play.png` - Ícone para "Gerar Despacho" (triângulo play)
- `file_text.png` - Ícone para "Gerenciar Modelos" (retângulo com linhas de texto)
- `message.png` - Ícone para "Histórico" (balão de mensagem)
- `settings.png` - Ícone para "Mensagens" (engrenagem)

## Características:

- **Formato**: PNG com transparência
- **Tamanho**: 20x20 pixels
- **Estilo**: Minimalista, monocromático (branco)
- **Compatibilidade**: Funciona em Dark/Light mode

## Personalização:

Se desejar substituir por ícones personalizados:
1. Mantenha o mesmo nome de arquivo
2. Use PNG transparente
3. Mantenha 20x20px para consistência
4. Reinicie a aplicação

## Fallback:

A aplicação funciona normalmente mesmo sem estes arquivos (fallback para texto).
